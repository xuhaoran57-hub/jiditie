# 潮汐线视觉规范 v0.2（M8-A）

## 方向

以“深海蓝背景 + 潮汐青交互 + 暖沙金提示”为独立视觉语言。车厢采用轻透视
的分层结构，角色采用小型全身轮廓和类型配件；不使用现实交通制服、站牌、Logo
或官方地图轮廓。画面保持高对比度和适度细节密度，保证 375px 竖屏下也能读出
门、角色、朝向和倒计时。

## 色彩

`#324964`、窗框 `#487796`、窗面 `#89b7d9`、内饰暗部 `#091423`、内饰地板
`#14283a`、站台盲道 `#d7ad59`。这些颜色不组成任何现实线路的品牌配色。

## 角色标记

- 玩家：潮汐青外套、背包、帽檐、胸前徽章、脚底投影和方向箭头。
- 常规/快步/慢行：分别使用雾蓝、暖橙、淡紫色，并有不同步频和轮廓配件。
- 行李旅客：沙金上衣 + 侧边行李箱。
- 手机乘客：潮青上衣 + 发光手机和抬手姿态。
- 同行小组：粉玫上衣 + 半透明同伴轮廓。

角色由头部、发型、上衣、裤脚、手臂、鞋和投影组成；圆形碰撞体只用于规则，
不再作为最终视觉轮廓。动画使用旅客 ID 的确定性相位，不改变模拟结果。乘客不绘制
持续性的行动方向线或速度尾迹，仅通过姿态、步频和位置表达行为。

精灵源文件：`generated/tideline-sprite.svg`。Canvas 当前仍保留几何回退，避免
微信基础库对 SVG 解码差异影响规则可玩性。

M8-A 样板实现位于 `src/render/station-renderer.ts` 和
`src/render/actor-renderer.ts`；真机确认风格后，再接入 PNG/SVG atlas 和四向
关键帧。

## 组件与动效

- 主按钮圆角 9px，中型卡片圆角 16px，结算面板圆角 22px。
- 疏导波纹生命周期 0.35s；触摸反馈 0.12s；事件提示条淡入 0.20s。
- 所有状态同时使用颜色、文字和形状表达，不依赖单一颜色区分。

## 相似性边界

资源只表现抽象的虚构城市通勤场景；不复刻任何现实线路的配色组合、站名、
车厢外形、广播语句、制服或标志。发布前需要由非制作者进行第二次相似性复核。
